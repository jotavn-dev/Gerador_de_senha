# Gerador de Senhas Seguras 🔐

Este é um script simples em Python que gera senhas aleatórias e fortes utilizando a biblioteca `secrets`.

## ✨ Funcionalidades
* Escolha do comprimento da senha.
* Uso de caracteres especiais, números e letras.
* Segurança aprimorada com a biblioteca `secrets`.

## 🚀 Como usar
1. Clone o repositório.
2. Execute o arquivo principal: `python Gerador_de_senha.py`
